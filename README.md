# Template Base: Spec-kit & Jira MCP Integration

Este é um repositório template desenvolvido para ser utilizado como base na criação de novos projetos ou integrado a repositórios já existentes. Ele fornece a estrutura essencial e as *skills* necessárias para conectar o **Spec-kit** e o **Jira** utilizando LLMs.

## 🚀 Objetivo e Funcionalidades

O principal propósito deste template é habilitar uma comunicação inteligente e **bidirecional** entre o ambiente de desenvolvimento (através de LLMs) e as ferramentas de gestão:

* **Do Jira para a LLM:** Utilizar o contexto e as informações presentes nos cards/tasks do Jira para interagir com o repositório e guiar a LLM na execução de tarefas.
* **Da LLM para o Jira:** Permitir o fluxo inverso, onde ações, diagnósticos ou comandos realizados através da LLM reflitam automaticamente em atualizações, comentários ou movimentações de cards diretamente no Jira.

## 🛠️ Tecnologias Envolvidas

* **Spec-kit:** Estrutura para padronização e automação de especificações.
* **Jira MCP (Model Context Protocol):** Protocolo de contexto para integração nativa com modelos de linguagem (como Claude Code).
* **LLM Integrada:** Inteligência artificial para orquestração de código e tarefas.
